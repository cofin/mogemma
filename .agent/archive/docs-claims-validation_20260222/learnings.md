# Learnings: Docs & Claims Validation

## [2026-02-22] - Claims-to-evidence audit

- **Implemented:** Claims inventory, removed marketing language, verified examples, updated optional dep guidance.
- **Learnings:**
  - Every claim must have explicit code path + test evidence.
  - Strip superlatives; reference only measured baselines.
  - Keep docs phase late — revalidate after implementation changes.
  - Example code rot is common — tie examples to tests or CI.
